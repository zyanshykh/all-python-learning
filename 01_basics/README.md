# 01. Python Basics 🐍

Welcome to the Basics section of the Python learning journey! This directory contains the foundational concepts of Python programming, broken down into simple, interactive scripts.

## 📂 Folder Structure

*   **`01_smart_start.py`**: Introduction to Python syntax, printing statements, and basic configurations.
*   **`02_challenge.py`**: A hands-down challenge script to test your understanding of initial concepts.
*   **`03_operators.py`**: Practical examples covering Arithmetic, Assignment, Comparison, and Logical operators.

---

## 🚀 How to Run These Files

Make sure you have Python installed. You can run any file using your terminal:

```bash
python 01_smart_start.py
```
