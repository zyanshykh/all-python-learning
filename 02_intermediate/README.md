# 02. Intermediate Python

Welcome to the Intermediate Python section! This folder contains concepts that bridge the gap between basic syntax and advanced software development.

## 📂 Folder Structure

*   **`01_functions_and_scopes.py`**: Learn about function definitions, arguments, return values, and variable scopes (`global` vs `local`).
*   **`02_advanced_data_structures.py`**: Deep dive into lists, dictionaries, sets, tuples, and built-in methods.
*   **`03_exception_and_file_handling.py`**: Master error handling with `try-except` blocks and reading/writing files safely.
*   **`04_oop_fundamentals.py`**: Introduction to Object-Oriented Programming (Classes, Objects, Attributes, and Methods).

## 🚀 How to Use
1. Clone the repository.
2. Navigate to this directory: `cd 02_intermediate`
3. Run any file using Python: `python <filename>.py`
