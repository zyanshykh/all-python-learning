# All Python Learning

Welcome to the **All Python Learning** repository! This project is a structured, comprehensive guide designed to take you from a complete beginner to an advanced Python developer through hands-on code examples and practical projects.

---

## 📁 Repository Structure

The repository is organized into progressive learning modules:

*   **`01_basics/`** – Core fundamentals (Variables, Data Types, Loops, Functions).
*   **`02_intermediate/`** – Deeper concepts (OOPs, File Handling, Exception Handling, Iterators).
*   **`03_advanced/`** – Advanced topics (Decorators, Generators, Concurrency, Metaprogramming).
*   **`04_projects/`** – Real-world applications and portfolio projects.
    *   `calculator-suite/` – A comprehensive calculator application exploring different UI/logic implementations.

---

## 🚀 Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites
Make sure you have Python installed (Python 3.10+ recommended). You can check your version using:
```bash
python --version
```
---
##Installation & Setup
Clone the repository

```git clone [https://github.com/zyanshykh/all-python-learning.git](https://github.com/zyanshykh/all-python-learning.git)```

## Navigate to the project directory:
```
cd all-python-learning
```
**(Optional) Create a virtual environment:**
```
python -m venv venv
source venv/bin/bin/activate  # On Windows use:
venv\Scripts\activate
```
